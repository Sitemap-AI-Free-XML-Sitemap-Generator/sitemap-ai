# Sitemap AI - Free XML Sitemap Generator

[Sitemap.ai](https://www.sitemap.ai) is a free XML sitemap generator and website crawler that helps you get indexed faster by search engines.

Sitemap.ai provides cloud XML + HTML sitemaps with JavaScript rendering, scheduled crawls, and website intelligence. It is free up to 5,000 URLs.

## Features

- Cloud XML sitemaps
- HTML sitemaps
- JavaScript rendering
- Scheduled crawls
- Website intelligence
- Free up to 5,000 URLs

Get started at https://www.sitemap.ai
